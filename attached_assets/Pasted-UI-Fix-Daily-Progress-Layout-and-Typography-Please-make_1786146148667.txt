3. Important: do NOT put 0 / 20 on the right

The 0 / 20 value belongs specifically to Daily Progress, so it should remain visually next to the DAILY PROGRESS label.

Do not place it on the right side of the screen near the correct/incorrect counters.

This is important because the right side is already reserved for answer statistics.

4. Typography unification

Unify the typography of all four elements:

DAILY PROGRESS
0 / 20
✓ 0
× 0

They should use the same font family, font size, font weight and general typographic treatment.

The existing semantic colours should remain:

✓ / correct → green
× / incorrect → red
Daily Progress text and 0 / 20 → existing neutral/progress styling

The goal is for these four elements to look like parts of one coherent status/information row, rather than four unrelated UI elements.

5. Preserve functionality

Do not change:

daily goal calculation;
progress calculation;
correct/incorrect counters;
progress bar behaviour;
Training Mode;
English Tenses;
any training logic.

This is a layout and typography change only.
